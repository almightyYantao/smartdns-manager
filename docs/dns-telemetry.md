# DNS 拨测

在「网络遥测」新建「DNS 拨测」目标，填写 DNS 服务器 IP、查询域名和预期 IPv4 地址。保存后可执行手动测试。控制台后端直接向指定服务器发起 UDP/53 查询，成功条件为 `NOERROR` 且 A 记录包含预期地址。手动测试立即显示结果，连续失败和恢复次数由定时任务统计。

在「任务管理」创建网络遥测任务，选择目标和周期。已有 DNS 目标会迁入每 30 秒执行的「DNS 自动拨测」任务。DNS 拨测连续 3 次失败触发「DNS 解析异常」，告警后连续 2 次成功触发「DNS 解析恢复」。在「通知管理」的全局渠道订阅这两个事件。通知包含 DNS 服务器、查询域名和结果。检测历史保留 7 天。

部署验收时，从控制台容器所在网络核验 DNS 目标的 UDP/53 路径。探测结果反映控制台网络的查询路径。节点 Agent 继续采集 SmartDNS 日志。

本地验证可在 `backend` 执行 `go test ./...`，在 `ui` 执行 `npm run build`。
