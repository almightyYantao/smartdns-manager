# SmartDNS 核心版本检测与升级

在「节点管理」点击「检测版本」，查看节点当前运行版本和发布源的稳定版本。可升级的节点会显示升级按钮。升级前填写一个该节点可以稳定解析的域名及其预期 IPv4 地址，确认后仅重启所选节点的 SmartDNS。升级会备份旧核心，验证失败时尝试恢复并再次验证。首版支持具有发行摘要的 Linux x86_64 和 aarch64 独立二进制，节点需要 `dig`、`base64`、`flock`、`sha256sum`、`timeout` 及运行权限。

在「系统设置 → 系统设置 → SmartDNS 核心发布源」配置版本元数据和升级包下载目录。默认使用 pymumu/smartdns 的 GitHub Releases，支持替换为控制台可访问的国内或内网 HTTPS 镜像。发布元数据应兼容 GitHub Releases 的 `tag_name`、`assets[].name` 和 `assets[].digest`，摘要格式为 `sha256:<十六进制摘要>`。下载目录按 `/发行标签/资产名` 组织。请使用可信元数据，镜像管理员应从官方发布同步原始摘要和二进制。

「验证并保存」从控制台验证元数据和一个可用架构的升级包。每次升级再校验所选架构的 SHA-256，节点从 SSH 接收二进制并在切换前复核摘要。控制台无法读取元数据时仍可检测节点当前版本。

无法访问在线发布源时，在同一页面点击「上传离线升级包」。ZIP 根目录放 `latest.json`，二进制按 `<发行标签>/smartdns-<架构>` 存放，元数据只列出包内资产及官方摘要。上传会校验摘要和 ELF 架构，成功后将该发行版设为升级目标。实际升级仍需在「节点管理」选择节点并确认。
